⚠ **One of the seven is blocking.** [OQ-69] is the first blocking row since [OQ-88] closed on
2026-08-11, and unlike [OQ-88] it is not a contradiction to be resolved by reasoning — it is a product
nobody has chosen yet. If only a few decisions can be made before the next planning session, make
these.

⚠ **And one that is no longer a question.** [OQ-88] used to head this list. **[DEC-66]** closed it, but
